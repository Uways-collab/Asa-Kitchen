# Àṣà Kitchen — Heritage, Refined

A world-class restaurant website for **Àṣà Kitchen**, a contemporary West African
restaurant in Victoria Island, Lagos. Wood fire, heritage spice and soulful
technique, plated with modern precision.

## ✨ Highlights

- **Immersive hero** — cinematic food photography, word-by-word headline reveal, rotating brand seal
- **Brand story** — the meaning of *àṣà* (Yoruba: "culture"), founder narrative, stats
- **Signature dishes** — four hero plates with hover-zoom media cards
- **Full menu** — tabbed à la carte (Small Plates · From the Fire · Swallow & Stew · Sweet · The Bar) in ₦
- **Experience** — Chef's Table, private dining, Sunday Table
- **Chef profile** — portrait, quote and bio
- **Testimonial slider** — autoplay, dots, arrows and touch swipe
- **Gallery** — editorial masonry grid with hover captions
- **Reservations** — validated form with floating labels and a live *open / closed* status pill (Lagos time)
- **Visit** — hours, directions, and a stylised vector map of Victoria Island
- **Footer** — newsletter, navigation, socials

## 🛠 Built with

- Semantic HTML5, modern CSS (custom properties, fluid `clamp()` type, grid, container queries-ready)
- Vanilla JavaScript — zero dependencies, IntersectionObserver reveals, accessible tabs/slider/forms
- Fraunces + Inter (Google Fonts)
- Fully responsive, keyboard accessible, `prefers-reduced-motion` respected

## 🚀 Run locally

Any static file server works:

```bash
python3 -m http.server 4173
# → http://localhost:4173
```

## 📁 Structure

```
index.html        # full single-page site
css/style.css     # design system + styles
js/main.js        # interactions
images/           # art-directed restaurant photography
```
